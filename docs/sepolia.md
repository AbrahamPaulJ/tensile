# Tensile on Sepolia

Generated by `tools/sepolia_page.py` from `deploy/sepolia.jsonl`, the record `tools/sepolia_run.sh`
keeps of every transaction it sends. Nothing here is typed by hand.

The contracts are the output of `fe build` (Fe 26.5.1, `-O 1`), deployed unchanged.
`bash tools/check_deployed.sh` fetches the code at each address from a public node and compares it
with a fresh build, byte for byte.

The two gas columns differ because the two chains do not charge the same. Every figure elsewhere in
this repository is measured on anvil at the Osaka fork, the rules of mainnet today (`docs/numbers.md`).
Sepolia has run the next fork, Glamsterdam, since 2026-10-06, and it charges more for creating state
(EIP-8037) and for reaching it (EIP-8038): a claim writes seven new storage slots, so it is the call
that grows most. The contract and the calls are the same.

Under those rules the node estimates `Network.classify`, the whole network in one transaction, at
1,907,017 gas (an estimate from `eth_estimateGas`, not a mined transaction), so the costliest
challenge is 18.7% of a full run there, against 9.4% on Osaka.

After the last step the arbiter holds exactly the burned half of three bonds, 0.0015 ETH, which
`burned()` reports and nothing can withdraw.

## Check it yourself

```
cast call --rpc-url https://ethereum-sepolia-rpc.publicnode.com 0x0645964d66b7fb8e53ae96064fb6669e2b3adaa5 "result(uint256)(uint8)" 0
cast call --rpc-url https://ethereum-sepolia-rpc.publicnode.com 0x0645964d66b7fb8e53ae96064fb6669e2b3adaa5 "claimInfo(uint256)(address,uint256,uint256,uint8,uint8)" 1
bash tools/check_deployed.sh
```

The first prints the finalised answer, 7. The second ends in the claim's status: 2 is slashed, 3 is
final. To repeat the whole run with your own key: `SEPOLIA_KEY_FILE=<file> bash tools/sepolia_run.sh`
after removing `deploy/sepolia.jsonl`.

## Open claims: be the watcher

claims about reference samples 1 to 12 that nobody has challenged. Some are false, on purpose.
[The watcher page](https://abrahampaulj.github.io/tensile/sepolia/) reads each one from the chain,
re-runs the network in the browser with the WebAssembly build of the kernel, names the wrong value,
and asks a public node whether the arbiter would accept the challenge. `node demo/test/sepolia.mjs`
does the same from the command line, and a scheduled workflow runs it every six hours. Anyone who
sends a challenge is credited half the bond.
