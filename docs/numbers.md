# Numbers

Generated by `tools/m4_numbers.sh`, the one command behind every gas and size figure this project
quotes. Change the script or the code, never this file. Real transactions on anvil (Osaka),
reference sample 0, each result checked against the NumPy reference or the protocol before its gas
is recorded. The demo page's chain reproduces the Fe figures of sections 1 and 2 exactly
(`demo/test/run.mjs` compares them).

fe 26.5.1 (149c758); forge Version: 1.9.0; solc 0.8.38, via-IR, optimiser 200 runs. Whole script: 747.7 s.

An honest claim costs `claim` + `finalize`, 295,147 gas; a dispute at layer 1, the worst case, costs
178,662 gas once. `classify` is 11.3% of the Osaka per-transaction cap of 16,777,216 gas.
