Be the watcher. These claims are open on Sepolia right now.

Someone posted answers of a neural network to a contract written in Fe, each with a bond. Some are lies. This page reads each claim from the chain, re-runs the network here with the same Fe kernel built for WebAssembly, names the first wrong value, and asks a Sepolia node whether the contract would accept the challenge. No wallet is needed to check. With one, you can send the challenge and be credited half the bond.
