    Why this is written in Fe

    Shapes and fixed-point scales live in the types, so a wrong model does not compile. Effects are in the signatures, so you can see which handler can move money. One source compiles three ways: to the EVM bytecode in step 1, to a native auditor, and to the WebAssembly module that checks every run in this page. All of this is real compiler output and quoted source.
