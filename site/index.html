Verifiable inference, written in Fe

A false answer on-chain, caught by re-running one neuron.

Tensile is an integer neural-network kernel written once in Fe, with shapes and fixed-point scales in its types. The same source runs natively and in WebAssembly to classify, and on the EVM to settle a dispute. Nobody pays to run the network on-chain. They post the answer with a bond, and anyone can prove a lie with a single neuron.

On a public chain: be the watcher

The same bytecode is on Sepolia. One arbiter there holds a dozen claims, some of them false on purpose. The watcher page reads each claim from the chain, re-runs the network in your browser with the Fe kernel built for WebAssembly, names the wrong value, and asks a public node whether the contract would accept the challenge. No wallet is needed to check, and with one you can send the challenge and be credited half the bond.

How a lie gets caught

The usual trouble with optimistic schemes is two code bases, one off-chain and one on-chain, that must agree down to the rounding of a negative number. Here there is one.

  1. Claim

    A claimant posts the answer, every hidden activation and every output, with a bond. The contract checks nothing yet and holds no weights.

  2. Watch

    A watcher re-runs the network off-chain with the same Fe kernel, native or WebAssembly, and finds the first value that differs.

  3. Challenge

    The watcher names that one value and presents the neuron's weights with a Merkle proof. The contract re-runs that neuron. If the claim was false, half the bond goes to the watcher and half is burned.

Why this is a Fe project

The types carry the model, and they cost almost nothing at run time: 2.1% of a neuron's execution gas against the same contract written over plain words.

// ingots/tensile/src/dense.fe
pub fn neuron<const IN: usize, const FW: usize, const F: usize>(
    row: Row<IN, FW>,
    x: Activations<IN, F>,
    bias: Q<{ F + FW }>,
) -> Q<{ F + FW }>
where dot_fits_i32(IN)
error[8-0000]: type mismatch
  │     dense(weights, x, bias)
  │                     ^^^^ expected `Bias<2, 14>`, but `Bias<2, 15>` is given
  • Scales are computed in the types. A bias must have the scale of a weight times an activation, F + FW fractional bits. Give it another and the model does not compile. 13 such wrong models are kept as tests.
  • Overflow is ruled out at compile time. The where clause is a compile-time function proving the accumulator fits in 32 bits for every possible input of that length.
  • Effects make the security argument readable. Of the arbiter's handlers, exactly one declares that it can send ETH.
  • The dispute rule is a pure function. dispute::step(claim, now, action) is the whole lifecycle, with no storage and no clock, tested on both backends.
  • Built on std where std has it: std::evm::merkle for proofs, Wei, Duration and Timestamp for the bond and the window. Q<F> exists because core::fixed is unsigned decimal, and a network needs signed binary fixed point.

Limits, plainly: one honest watcher is assumed, as in every optimistic protocol. Small dense networks only. Not audited.
